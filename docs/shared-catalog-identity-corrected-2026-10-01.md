# 共享目录快照中的规范文件身份

候选未满足预定条件，不合入生产实现。 本次为启动和 dpkg 组件对照，不能证明完整 357 包安装低于 180 秒；完整安装目标仍未完成。

原实现已固定全部目录映像，却在每个 worker/fork 的注册表重建过程中，为 29 个模块逐个调用 `GetFinalPathNameByHandleW`。候选在会话拥有者首次构造共享目录快照时，从同一个禁止写入和删除的文件句柄取得规范路径，随只读快照传送；客户机保留相同文件 pin，并直接使用快照中的身份。快照格式标记升级为 `KZCAT002`，路径采用有长度上限的 UTF-16 编码，保留 Windows 非 Unicode 文件名。

没有按可重用句柄编号或路径名引入全局缓存。普通目录发现仍查询实际文件句柄；共享快照只由已认证的 init 构造。回归测试验证发送者释放后接收者仍固定文件，文件及祖先目录不能被重命名，最后一个接收者释放后目录可重命名；另覆盖 Unicode 路径、未配对 UTF-16 代理项、截断、空路径、相对路径、NUL 和超长数据。

两边均包含已验证的原生符号链接修复（`ff12782`），并使用完整普通 Release，冻结 1951 个源码输入及各 61 个分发文件。候选仅修改 bridge 的快照和身份实现及测试；没有加入上一轮淘汰的 DLL 加载捷径。原 R23 因基线原生符号链接缺陷未进入测速，相关失败与修复见[记录](native-symlink-install-2026-10-01.md)。本轮以修复后的 R25 为对照，仅比较目录身份优化。固定三轮 A/B/B/A，全部 12 个样本保留。每个样本运行 128 次 fork/wait、100 次 shell exec，以及两次真实 dpkg 解包/配置（128 个文件、16 个维护脚本子进程）。主机未独占，本会话测速期间没有编译或运行其他基准。
