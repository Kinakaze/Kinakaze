# Kinakaze v1.0.0

在 Windows x86-64 上直接运行 Linux x86-64 程序的用户态兼容层。

本版本改进文件 I/O、软件包安装和启动热路径，并修复进程组、文件锁和动态 TLS 兼容性。

## 主要变化

- 优化 VFS 原生路径查找、元数据访问、写回和共享缓存，改进 apt/dpkg、Node.js/npm 安装相关热路径。
- 改进映像缓存和 worker 预热，默认通用预热池使用两个未执行 worker；优化稀疏内存复制与 fork 路径。
- 修复 Bash 管道中已退出但未回收的组长导致的 `setpgid` 失败，支持 OFD 文件锁并修复 utmp 的锁和定位操作。
- 优化 syscall、ptrace 和陷阱查找路径，改进账户数据库查询、后加载静态 TLS 与扩展精度复数数学支持。
- 补充回归探针、软件包安装基准和性能分析记录。

## 使用

下载 `Kinakaze-1.0.0-windows-x86_64.zip`，解压到新目录后运行 `init.exe`。首次启动联网准备 Debian bookworm 环境，宿主无需 Python。升级前退出旧环境。

要求 Windows 11 24H2 或 Windows Server 2025 及以上、x86-64。源码构建使用 Rust 1.95.0、MSVC、LLVM 和 Python 3.13。提供运行包、源码 ZIP 及各自的 SHA-256 文件；发布工作流检查构建、核心测试、首次安装和 ZIP 解压运行。
