# Kinakaze v0.1.0

首个正式版本，提供 Windows x86-64 运行包与源码包。

宿主需安装 Microsoft Visual C++ x64 运行库（`VCRUNTIME140.dll`）。

- 可选清单初始化完整基础 rootfs：外部 `--rootfs-manifest` 优先；只有目标目录不存在或为空时才安装，已有非空 rootfs 保持原样。
- 安装文件包含原生模块、共享运行库、基础配置、BusyBox 与锁定依赖。离线安装，逐文件 SHA-256 校验，失败不会留下半成品 rootfs。
- `init --session-file` 创建长驻会话；独立的 `init launch --parent PID` 客户端可向已有进程树启动程序，支持工作目录、环境变量、等待及退出码。
- 去除固定 Java/Minecraft 版本路径，修正原生指针接口约束与无效代码，补齐边界测试和发行工具。

运行方式、清单格式和进程树示例见 `docs/runtime-release-v0.1.0.md`；运行 ZIP 内的 `README.md` 提供相同说明。默认 rootfs 是完整基础运行环境，不包含 Java/Minecraft 或编译开发环境。

归档附带 SHA-256、许可证、客体包对应源码和运行验证报告。测试在 Windows x86-64 上进行，覆盖独立临时目录、空 PATH、并发初始化和真实客体进程父子关系；尚未在另一台全新 Windows 主机上验证。项目仍有历史 Clippy 风格及 ABI 命名警告，应用兼容性以实际验证范围为准。

Git 作者与提交者均为 **mitsukina**。

发布验证：1,853 项 Rust 测试通过、0 失败、27 项现有忽略；43 项 Python 测试通过；5,721 个客体导出检查通过；全工作区 Clippy、管理 smoke 和 8 项发行运行验收通过，ZIP 解压后复验通过。
