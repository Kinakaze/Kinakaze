# Kinakaze v1.4.0

本版包含最新 main 的 fork、VFS、文件向量 I/O 和同步优化。

- fork 的私有 COW 页面复制跨查询批次合并连续区域；共享文件描述符使用已测量的紧凑链接头布局。
- 保留选定的原生文件打开路线并覆盖相对路径写入。普通小文件创建将模式、umask 和 SGID 归属与文件一同原子初始化，减少路径解析与元数据重开。
- 私有写句柄复用实时 verity 检查，减少写入路径的重复打开，保留 verity 启用后的写保护。
- 密集的小段文件 readv/writev 共用一次 inode 固定和位置事务，保留部分传输、共享偏移、权限及信号语义。
- 优化 pthread 优先级继承互斥、futex 批量等待和实时截止时间处理；具名 Unix 数据报使用共享谓词事件唤醒。
- 严格 Node.js/npm 安装基准要求 debconf 预配置成功，增加完整离线 npm 小文件安装与集成兼容性验证。

生产代码保留各组件已测量的选定路线。性能证据、对照条件及局限见仓库 docs；完整 apt 安装 Node.js/npm 的 180 秒目标尚未达到，本版不宣称达到该目标。

发行流程检查格式、全部编译目标、核心库、原生构建及 worker，并验证 Windows 运行时首次启动和解压后启动。发布源代码 ZIP、Windows x86-64 运行时 ZIP 及各自的 SHA-256 校验文件。
