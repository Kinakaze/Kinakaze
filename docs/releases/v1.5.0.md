# Kinakaze v1.5.0

本版包含异步数据回写、fork 快照刷新、原生库复用，以及 1Panel 商店应用实测中发现的 ABI 修复。

- init 持有有界的数据回写队列，回写请求在提交进程退出后仍会完成；等待者和会话关闭会提前处理排队请求，完整 fsync 屏障保持不变。
- 所有权未变化的 `fchown` 复用已固定的原生描述符，并保留权限、set-ID/capability 清除检查；只读创建的新文件仍可通过创建时获得的句柄完成首次写入。
- fork 周期性把 C 堆和加载器持有的 ELF 映像刷新为新的 COW 代际，减少后续 fork 对已私有化页面的重复复制；`KINAKAZE_FORK_HEAP_REFRESH=0` 可关闭。
- 共享库和 provider DLL 通过已保留的文件固定句柄加载，不再逐个重新打开路径；`KINAKAZE_NATIVE_LIBRARY_REUSE=0` 恢复原路径。
- 补齐 C11 线程、`getsubopt`、`closefrom`、`strtouq`、`__sigaction`、`_SC_IOV_MAX` 等 ABI，增加长双精度和 signaling 数学函数；文件映射在文件增长和 `PROT_NONE` 恢复后保持按字节精确的长度。
- AOT 缓存格式升至 37，读取静态 glibc 程序中未索引的 `.eh_frame` 记录。

性能数字来自同机对照诊断，不是完整安装的验收结果：apt 安装 Node.js/npm 的 180 秒目标尚未达到，也没有原生 Linux 对照。1Panel 商店 265 个应用中仅少数场景通过，其余未覆盖或失败，详见 `docs/1panel-app-compatibility-2026-10-01.md`；不宣称商店应用或完整 Linux ABI 已兼容。

发行流程检查格式、全部编译目标、核心库、原生构建及 worker，并验证 Windows 运行时首次启动和解压后启动。发布源代码 ZIP、Windows x86-64 运行时 ZIP 及各自的 SHA-256 校验文件。
