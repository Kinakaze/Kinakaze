# Kinakaze v0.2.0

Windows x86-64 运行包现在自带程序、依赖 DLL 和默认 Debian 安装清单。解压 `Kinakaze-0.2.0-windows-x86_64.zip`，双击 `init.exe` 或 `worker.exe`，首次启动会联网下载并配置环境，随后进入 Bash；Windows 无需安装 Python 或其他解包工具。

## 本次更新

- 默认安装 Debian bookworm 无桌面基础与标准命令行环境，共 306 个锁定软件包，包含 Bash、APT/dpkg、编辑器、Python/Perl、网络工具和 OpenSSH。
- 下载与客体 APT 默认使用中科大 Debian 镜像。安装器自动跟随 Windows 系统代理；可通过 `rootfs.manifest.json` 修改镜像、禁用代理，也可使用 `KINAKAZE_DEBIAN_MIRROR`、`KINAKAZE_DEBIAN_SECURITY_MIRROR`、`KINAKAZE_DOWNLOAD_PROXY` 环境变量覆盖。启动窗口实时显示下载和安装进度。
- 同一 rootfs 共用一个常驻进程树。客体 PID 1、开机脚本、终端和关机命令由清单配置；默认使用 systemd 的 `kinakaze.target` 启动 SSH 与会话服务，也支持其他 init。
- Bash 与裸 ELF 应用共用可断开重连的交互终端。关闭终端窗口或按 `Ctrl+]` 只断开连接；托盘右键可返回终端、打开 WebUI，或关闭整个进程树。
- 修复鼠标移动时终端出现控制序列的问题，优化关机响应、原生模块加载和应用启动性能，完善 libc 正则、VFS、socket、定时器、信号及 X11 行为。
- 更新 WebUI 程序启动、参数与环境设置、进程详情、筛选排序和主题。
- 运行 ZIP 不附带 `docs/`、构建/验证报告或重复 CMD 入口；许可材料集中保留在 `licenses/`。

## SSH 连接

默认开机会启动 SSH，仅监听本机 `127.0.0.1:2222`：

```powershell
ssh -p 2222 root@127.0.0.1
```

默认密码为 `kinakaze`，可在客体内运行 `passwd` 修改。首次启动自动生成主机密钥，后续启动保留密码、密钥和配置。`worker.exe setup` 只安装环境；启动默认会话后才启动服务。

## 升级与适用范围

已有非空 rootfs 不会重新安装或覆盖；新默认镜像、服务配置只用于首次安装，已有环境需自行调整对应客体配置。请先从托盘关闭旧环境，再更新程序文件。

这是运行在 Windows ABI 兼容层中的 Debian 用户空间。默认 systemd 目标启动适配后的服务，不包含完整的硬件、udev 和 journald 开机链；需要专有 Linux 内核接口或设备驱动的程序仍须单独验证。

本页附带 Windows 运行 ZIP、对应源码 ZIP 及各自 SHA-256 校验文件。源码和详细使用说明见 [Kinakaze 仓库](https://github.com/Kinakaze/Kinakaze/tree/v0.2.0)。
