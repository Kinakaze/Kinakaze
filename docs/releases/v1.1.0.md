# Kinakaze v1.1.0

本版合入已完成的运行时、fork 和 VFS 优化，以及当前工作区的 manifest、工具和兼容性修复。

- 原生文件读取、已有文件写入和独占创建保留 inode 句柄，减少重复路径解析和打开。
- fork/exec 预备进程、写入跟踪和进程存活检查改进。
- 共享 pthread 条件变量、稳健互斥和 futex PI/requeue 支持。
- 修复基础包的 debconf 版本视图，保留 Debian 原版 apt-extracttemplates；同时覆盖在线和离线发行清单。
- 增加进程优先级、scanf 分配、Redis CLI 和 Debian 软件批量兼容性验证工具。

性能记录与原始验证范围见仓库 docs。完整 Node.js/npm 安装的 180 秒优化目标尚未达成；本版不宣称达到该目标。失败的原生重命名原型作为实验补丁保存，没有启用。

发行流程验证源代码包、Windows 运行时首次启动和解压后启动，发布两个 ZIP 及各自的 SHA-256 校验文件。
