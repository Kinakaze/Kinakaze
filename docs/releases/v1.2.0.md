# Kinakaze v1.2.0

本版合入经过对照测试选择的 fork、VFS、文件向量 I/O 和同步优化。

- fork 的私有 COW 页面复制跨查询批次合并连续区域，减少远程内存操作。
- 压缩共享文件描述符链接头，保留已测量的原生文件打开路线，并覆盖相对路径写入。
- 密集的小段文件 readv/writev 共用一次 inode 固定和位置事务，保留部分传输、共享偏移、权限及信号语义。
- 优化 pthread 优先级继承互斥、futex 批量等待和实时截止时间处理；具名 Unix 数据报使用共享谓词事件唤醒。
- 完整 Node.js/npm 安装基准要求 debconf 预配置成功，保存组件新旧对照及完整安装证据。

生产代码保留各组件已测量的选定路线。组件收益及测试条件见仓库 docs；完整安装的 180 秒目标尚未达到，本版不宣称达到该目标。

发行流程检查格式、全部编译目标、核心库、原生构建及 worker，并验证 Windows 运行时首次启动和解压后启动。发布源代码 ZIP、Windows x86-64 运行时 ZIP 及各自的 SHA-256 校验文件。
