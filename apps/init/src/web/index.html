使用说明

启动程序

输入 Linux 绝对路径，如 /bin/sleep。参数分别添加，含空格时无需再加引号。首页的“运行示例”会填入 /bin/sleep 60。

查看输出

程序输出与错误信息显示在启动 Kinakaze 的终端。此入口不接收交互输入；交互式 shell 请使用 worker.exe run -- /bin/sh。

运行环境

待命进程用于启动新程序，由 Kinakaze 自动管理。需要完整的启动入口时，在发行目录运行：

.\init.exe --session-file .\session.json --web 127.0.0.1:0

打开终端显示的地址。关闭 init 会结束本会话的所有程序。

资源采样

内存来自 Windows 宿主；CPU 以单核为 100%，多核可超过 100%。— 表示采样不可用。页面隐藏时暂停自动采样。
